# Problems and hints

Rendered pages: **https://pareek21.github.io/insight-gen-problems/**

The eight research problems from our experiments on how much of a proof a language model needs as a hint before it
can prove the result, each with the hints that appear in our summary tables, their sizes (exact token counts, as a
share of the reference proof's length) and how each model did with them. Hints were written by GPT-6 Astra (pro)
from the reference proofs; the proofs themselves are not included.

Problems 5–8 are from OpenAI's math release (https://github.com/openai/math, commit 1581d4c, Apache-2.0); their
statements are the release's definitions and theorems, posed as "Determine whether …". The other statements were
written for this study from the sources listed on each page.

The pages are generated by a script in our (private) experiment repository; edits made here directly would be
overwritten.
