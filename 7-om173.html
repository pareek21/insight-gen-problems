#173 Seymour

Seymour's conjecture (1990s). OpenAI release, Sept 2026. True.
Reference proof: 10,362 tokens. Statement: the definitions and theorem from OpenAI's math release (commit 1581d4c, Apache-2.0), posed as “Determine whether …” so that the answer isn't given away.

Problem

An oriented graph is a finite directed graph with no loops, no multiple arcs, and no pair of opposite arcs. Its underlying undirected graph need not be complete or connected. For a vertex $v$, write

$$N_1^+(v)=\{u:v\to u\},\qquad N_2^+(v)=\{w\notin\{v\}\cup N_1^+(v):\ \text{there is a vertex } u \text{ with } v\to u\to w\}.$$

Thus $N_2^+(v)$ consists of the vertices at directed distance exactly two from $v$. Each vertex is counted once, regardless of the number of paths reaching it.

Determine whether every nonempty finite oriented graph has a vertex $v$ such that

$$\lvert N_1^+(v)\rvert\le\lvert N_2^+(v)\rvert.$$

Prove your answer.
